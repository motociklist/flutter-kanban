# Функциональность Перетаскивания Задач (Drag & Drop)

## Описание

В этом проекте реализована полная функциональность перетаскивания задач между колонками Kanban-доски с автоматическим обновлением статуса задачи в Firestore.

## Как это работает

### 1. Визуальное перетаскивание
- **Draggable виджеты**: Каждая карточка задачи обёрнута в `Draggable<KanbanTask>` 
- **DragTarget**: Каждая колонка имеет `DragTarget<KanbanTask>`, который принимает перетащенные задачи
- **Визуальная обратная связь**:
  - При начале перетаскивания карточка становится полупрозрачной (opacity: 0.4)
  - При наведении на целевую колонку она подсвечивается зелёной рамкой
  - Копия карточки следует за курсором мыши

### 2. Обновление статуса
Когда задача попадает на целевую колонку:

```dart
void _moveTask(KanbanTask task, KanbanStatus to) {
  // 1. Проверяем, что статус действительно изменился
  // 2. Обновляем статус в локальном списке (UI)
  // 3. Отправляем обновление в Firestore
  // 4. Показываем уведомление об успехе или ошибке
  // 5. При ошибке откатываем изменение в UI
}
```

### 3. Состояния задачи

Статусы отображаются цветными тегами на карточках:

| Статус | Цвет | Описание |
|--------|------|---------|
| **To Do** (К выполнению) | Синий | Новая задача, не начата |
| **In Progress** (В процессе) | Оранжевый | Задача в работе |
| **Done** (Завершено) | Зелёный | Задача выполнена |

### 4. Технические детали

#### Файлы, участвующие в функциональности:

- **`lib/widgets/kanban_column.dart`**: Целевой контейнер для перетаскивания
- **`lib/widgets/kanban_card.dart`**: Карточка задачи для перетаскивания
- **`lib/pages/kanban_page.dart`**: Логика обновления статуса и взаимодействие с Firestore
- **`lib/services/firestore_task_service.dart`**: Сохранение обновлений в Firestore

#### Валидация:

```dart
// Колонка не принимает задачи, которые уже в этом статусе
onWillAcceptWithDetails: (details) => details.data.status != status
```

#### Обновление Firestore:

```dart
// После успешного перетаскивания
await _taskService.updateTask(updatedTask);
```

## Использование

### Перетащить задачу:
1. Нажать и удержать карточку задачи
2. Перетащить её в нужную колонку
3. Отпустить мышку

### Результат:
- Статус задачи обновляется в реальном времени
- Изменение сохраняется в Firestore
- Показывается уведомление об успехе/ошибке
- Задача автоматически перемещается в нужную колонку

## Обработка ошибок

Если при обновлении в Firestore произойдёт ошибка:
1. Изменение откатывается в UI (задача возвращается на своё место)
2. Пользователю показывается красное уведомление об ошибке
3. Проверка логов: `flutter run -d chrome` (для веб) или другой девайс

## Firebase Rules

Убедитесь, что в Firestore установлены правила безопасности, разрешающие пользователям обновлять свои задачи:

```firestore
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/tasks/{taskId} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

## Примеры кода

### Пример добавления новой колонки:

```dart
KanbanColumn(
  title: 'New Status',
  status: KanbanStatus.newStatus,  // добавьте в enum
  tasks: _byStatus(KanbanStatus.newStatus),
  onTaskDropped: _moveTask,
  onTaskTap: _editTaskDialog,
)
```

### Пример настройки цветов:

Цвета определяются в методе `_colorForStatus()` в `kanban_page.dart`:

```dart
Color _colorForStatus(KanbanStatus status, BuildContext context) {
  switch (status) {
    case KanbanStatus.todo:
      return const Color(0xFFE3F2FD); // голубой
    case KanbanStatus.inProgress:
      return const Color(0xFFFFF3E0); // оранжевый
    case KanbanStatus.done:
      return const Color(0xFFE8F5E9); // зелёный
  }
}
```

## Отладка

### Логи:
- При начале перетаскивания: `Начало перетаскивания: {task.title}`
- При отмене: `Перетаскивание отменено: {task.title}`
- При успехе: `Задача "{task.title}" успешно перемещена в {status}`

### Запуск с логами:
```bash
flutter run -d chrome --verbose
```
